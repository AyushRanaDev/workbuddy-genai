# Gig Worker Companion Prototype

## Build
- Replace the starter home screen with a polished, mobile-first worker companion with a distinctive worker photo and an immediately usable support chat.
- Offer targeted paths for earnings, safety, worker rights and welfare, document help, and grievance drafting, plus a simple language selector.
- Make every assistant answer a local canned mock; provide a transparent evaluator control for simulated service errors and a visible mock fallback. No real AI calls or hidden breakage.
- Use one chat with browser-only history as the safe prototype default; label demo figures and legal/scheme guidance as illustrative.

## Technical details
- Use the existing TanStack Start index route and token-based styling; render chat with installed AI Elements primitives.
- Add focused tests for mock-only response/fallback selection, then run project tests and inspect the live page on mobile and desktop.
